          Studio — version

          ComfyUI (tunnel SSH)

          L'interface complète de ComfyUI dans le navigateur de ton ordinateur, par un tunnel SSH chiffré de bout en bout entre ton ordinateur et le Pod. Les images que tu y crées arrivent aussi dans la galerie de Studio.

          Première fois (à faire une seule fois)
          1. Crée ta clé SSH sur l'ordinateur. Dans PowerShell (Windows) ou le Terminal (Mac) :
            ssh-keygen -t ed25519
            Valide les questions avec Entrée (une phrase de passe est possible). Le fichier id_ed25519 est ta clé privée : il ne doit jamais quitter ton ordinateur ni être envoyé à qui que ce soit.
          2. Affiche ta clé publique et copie la ligne qui commence par ssh-ed25519 :
            Windowstype $env:USERPROFILE\.ssh\id_ed25519.pub
            Maccat ~/.ssh/id_ed25519.pub
          3. Colle-la dans Runpod : Settings → SSH Public Keys. Une clé publique n'est pas un secret.
          4. Dans ton modèle Runpod, mets 22 dans « Expose TCP Ports », puis déploie un nouveau Pod.

          Le tunnel ne donne accès qu'à ComfyUI : ni terminal, ni autre service du Pod, connexion par clé uniquement. Le port 22 ouvert par Runpod peut recevoir des tentatives de connexion d'inconnus, toutes refusées sans ta clé ; le serveur SSH ne tourne que lorsque tu l'actives ici. Les workflows enregistrés dans ComfyUI restent en mémoire vive : exporte ceux à garder avant de terminer la session.
